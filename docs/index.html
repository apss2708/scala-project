01

One trait, three channels

EmailChannel, SmsChannel, and PushChannel implement NotificationChannel. Adding another doesn't touch the service.

02

Immutable messages

Sealed case classes give each message type its own fields, plus generated IDs, timestamps, and safe structural equality.

03

Failures you can see

Custom exceptions and Either[NotificationException, DeliveryReceipt] make failed deliveries typed values, not surprises.

04

Retries included

Exponential back-off retries only transient provider failures. Validation errors fail fast. 17 MUnit tests cover the behavior.
